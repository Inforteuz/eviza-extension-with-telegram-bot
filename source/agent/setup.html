Brauzer skripti — sinov

Brauzer rejimi tekshirilmoqda…

  1. Chrome yoki Edge’da Tampermonkey o‘rnating. Kengaytma sozlamasida Allow User Scripts ruxsatini yoqing.
  2. eVisa skriptini o‘rnating. Kod ochilsa, uni Tampermonkey → Create a new script oynasiga qo‘ying va saqlang.
  3. Quyidagi tugma bilan skript rejimini yoqing. Ulash kodini nusxalang.
  4. Saudi eVisa sahifasida “Ulash”ni bosib kodni kiriting, keyin “Ishga ruxsat”ni bosing.
  5. Telegramda ariza yoki guruhni tasdiqlab boshlang. Shu kompyuter va brauzer ochiq tursin.
To‘lovni operator bajaradi. Kodni boshqa odamlarga bermang. Jonli individual va guruh sinovlari alohida tekshiriladi.
